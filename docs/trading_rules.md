## 1. 스캔 조건 (15:15 KST 자동 실행)

### 1단계 — 거래대금·시총 필터

| 항목 | 기준 | YAML 키 |
|------|------|---------|
| 대상 시장 | KOSDAQ | `market` |
| 시가총액 하한 | **900억 원 이상** | `min_market_cap` |
| 시가총액 상한 | **4,000억 원 이하** | `max_market_cap` |
| 당일 거래대금 | **50억 원 이상** | `min_live_volume_amt` |
| 선발 기준 | 거래대금 내림차순 | — |
| 최대 선발 수 | **상위 20종** | `top_n` |

### 2단계 — MA 추세 프리필터 (확정 데이터 `.iloc[:-1]` 기준)

| 조건 | 판정식 | 차단 대상 |
|------|--------|---------|
| 데이터 충분 | `len(df) >= 122` | 상장 6개월 미만 신규 상장주 |
| MA20 우상향 | `MA20[-1] > MA20[-2]` | 단기 하락 추세 종목 (급락주) |
| MA60 우상향 | `MA60[-1] > MA60[-2]` | 중기 하락 추세 종목 |
| MA120 우상향 | `MA120[-1] > MA120[-2]` | 장기 하락 추세 종목 |
| 정배열 (60일선 상주) | `종가[-1] > MA60[-1]` | 60일선 하부 역배열 종목 |

> **4조건 전부 AND** — 하나라도 미충족 시 유니버스에서 즉시 제거

## 2. 매수 조건 (15:20 KST 자동 실행)

스캔 통과 20종에 대해 아래 조건을 **전부(AND)** 충족해야 매수 주문을 발행한다.

> MA 산출 기준: 당일 미완성 캔들 제외 (`confirmed = close.iloc[:-1]`)

### 조건 상세

| 순서 | 조건명 | 판정식 | 의미 |
|------|--------|--------|------|
| ① | MA20 이하 (바닥권) | `당일 종가 ≤ confirmed MA20[-1]` | 20일선 아래에서 눌림 확인 |
| ② | MA20 우상향 (단기 추세 인터록) | `MA20[-1] > MA20[-2]` | MA20이 꺾이는 낙폭 종목 차단 |
| ③ | 변곡 돌파 | `당일 종가 > confirmed 20일 전 종가` | 저항선 상향 돌파 확인 |
| ④ | MA60 우상향 | `MA60[-1] > MA60[-2]` | 중기 추세 정배열 |
| ⑤ | MA120 우상향 | `MA120[-1] > MA120[-2]` | 장기 추세 정배열 |
| ⑥ | 종가 > MA120 | `당일 종가 > MA120[-1]` | 장기 이평선 위 안착 확인 |

### 자금 관리

| 항목 | 기준 | YAML 키 |
|------|------|---------|
| 슬롯당 베팅금 | **5만 원 고정** | `bet_amount_per_slot` |
| 최소 운용 자본 | 5만 원 미만 시 매수 셧다운 | `minimum_operational_capital` |
| 매수 수수료 | 0.015% | `buy_cost_ratio` |

## 3. 매도 조건 (장중 0.5초 감시)

매수 체결 후 **3가지 청산 트리거** 중 가장 먼저 도달한 조건으로 익일 시가 매도.

| 조건명 | 기준 | YAML 키 | 비고 |
|--------|------|---------|------|
| 익절 | 매수가 대비 **+8%** | `target_profit_ratio` | High 기준 도달 시 즉시 |
| 손절 | 매수가 대비 **-3%** | `stop_loss_ratio` | Low 기준 도달 시 즉시 |
| 타임스탑 | 보유 **4 영업일** 경과 | `max_hold_days` | 15:30 정산 시 종가 청산 |

| 항목 | 기준 |
|------|------|
| 감시 주기 | 0.5초 |
| 장중 감시 구간 | 09:00 ~ 15:30 |
| 매도 수수료 + 세금 | 0.195% |

## 4. 전체 파이프라인 요약

```
[08:50] KIS 잔고 동기화 (이월 보유종목 확인)
    ↓
[15:15] 스캐너 실행
        1단계: 시총 900억~4,000억 + 거래대금 50억↑ → 상위 20종
        2단계: 일봉 122개↑ + MA60/120 우상향 + 종가>MA60 프리필터
    ↓
[15:20] 진입 연산
        ①당일종가≤MA20 ②MA20우상향 ③변곡돌파 ④MA60우상향 ⑤MA120우상향 ⑥종가>MA120
        → 전부 통과 시 5만 원 단위 주문 발행
    ↓
[장중] 0.5초 감시
        익절 +8% / 손절 -3% / 타임스탑 4일
    ↓
[15:30] 일일 정산 (보유일수 +1, KIS 자산 스냅샷 저장)
```
