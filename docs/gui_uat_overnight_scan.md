# GUI 인수(UAT) 체크리스트 — 오버나이트 스캔

**대상 시나리오:** 실제 GUI에서 **스캔 중단 버튼 연타**, **네트워크 끊김**.  
**전제:** 프로젝트 루트에서 앱 실행. 종료일·시장은 시나리오마다 동일하게 유지하면 재현 비교가 쉬움.

---

## 준비

- [ ] 앱 실행 전 `config/settings.yaml`의 `v3_0.universe_limit` 확인(기본 100 등).
- [ ] `.env`에 `KRX_ID` / `KRX_PW` 유무 각각 한 번 확인(있음·없음 시나리오 분리 가능).
- [ ] 테스트 PC에서 **네트워크 차단 방법** 준비(Wi‑Fi 끔, LAN 분리, 방화벽 규칙, 비행기 모드 등).

---

## A. 스캔 시작 전 UI

- [ ] **준비 상태:** 하단 상태가 오류 없이 표시되고 `스캔 중단`은 비활성(또는 눌러도 무응답과 동일)인가.
- [ ] **오버나이트 스캔 시작** 후: 스캔 실행 버튼이 비활성화되고 `스캔 중단`이 활성화되는가.

---

## B. 중단 버튼 연타 — 정상 네트워크

- [ ] 스캔 직후 **중단 1회:** 상태가 사용자 취소로 안내되고, 리스트가 이번 실행 결과로 헷갈리게 덮이지 않는가.
- [ ] 스캔 직후 **중단 버튼 5~10회 연타:** 앱이 **크래시·무응답** 없이 끝나는가.
- [ ] 연타 후: 버튼·커서가 **대기 상태**로 복귀하는가.
- [ ] 연타 후 **스캔 재시작**이 정상인가(연속 2~3회).

---

## C. 중단 버튼 연타 — 느린 구간

- [ ] 스캔이 **수 초 이상** 걸리는 상황에서 **중단 연타:** 크래시 없이 UI 복구되는가.
- [ ] (가능하면) **벌크 실패 후 폴백** 직후 **중단 연타:** 워커가 멈추고 UI가 복구되는가.

---

## D. 네트워크 끊김 — 스캔 도중

### D-1. 스캔 시작 직후 차단

- [ ] 스캔 버튼 클릭 직후 **즉시 네트워크 차단:** 앱이 **즉시 종료되지 않는**가.
- [ ] 수 초 대기 후 **네트워크 복구:** 추가 조작 없이 다시 스캔 시도 시 정상인가(또는 재시작 1회 후 정상).

### D-2. 스캔 중간 차단

- [ ] 스캔 진행 중 **네트워크 차단:** 오류·타임아웃·빈 결과 등 **정리된 종료**인가(무한 대기 아님).
- [ ] 이때 **중단 1회:** UI가 대기 상태로 돌아오는가.

### D-3. 스캔 중간 차단 + 중단 연타

- [ ] 오프라인 상태에서 **중단 연타:** 크래시 없음, UI 복구, 온라인 복구 후 재스캔 가능.

---

## E. 네트워크 끊김 — 스캔 시작 전

- [ ] **오프라인**에서 스캔 시작: 에러·안내 후 앱이 **정지하지 않는**가.
- [ ] 온라인 복구 후 **동일 절차**로 스캔 성공하는가.

---

## F. 데이터·로그(권장)

- [ ] `output/v31_scanner_debug_log.txt` 갱신 시, 중단·오프라인 후에도 파일이 정상 열리는가.
- [ ] (콘솔에서 GUI 실행 시) 스택 트레이스 없이 종료되는가.

---

## G. 통과 기준 요약

- [ ] **중단 연타·오프라인**에서도 **프로세스 예외 종료 없음**.
- [ ] **버튼·커서·busy 상태**가 **일관되게 복구**됨.
- [ ] **스캔 재실행**이 **연속 3회** 이상 문제 없음.
