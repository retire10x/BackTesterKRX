# BackTesterKRX 작업지시서 (국장 퀀트 백테스터)

이 글은 **무엇을 만들지**, **어떤 순서로 만들지**, **숫자는 어떻게 낼지**를 적어 둔 공식 기준이다.

---

## 1. 프로젝트가 하는 일

- **목적:** 실전 매매 연동 **없음**. 과거 데이터만으로 가설을 검증하는 **순수 백테스트** 프로그램.
- **핵심 가치:** 봉 주기, 이평선 **N**, 종목 선택을 바꿀 때마다 **성적표 + 정적 그래프**가 갱신되어, 아이디어를 빠르게 확인할 수 있게 한다.

---

## 2. 이 프로그램이 하지 않는 일

- 실시간 자동 매매.
- 증권사 API 주문 연동.

---

## 3. 매매 규칙 (신호 정의 + 체결)

**용어:** “이평선” = 사용자가 정한 **N기간** 이동평균(종가 기준).

### 진입 (골든크로스)

- 전일 종가 ≤ 이평선, 당일 종가 > 이평선 → 그날 **종가**에서 신호 확정.

### 청산 (데드크로스)

- 전일 종가 ≥ 이평선, 당일 종가 < 이평선 → 그날 **종가**에서 신호 확정.

### 체결

- 신호는 **그 봉 종가**에서 확정.
- 가상 체결은 **다음 봉 시가**다. (일봉 → 다음 거래일 시가, 주봉 → **다음 주 봉의 시가**.)

### 비용

- 매수 수수료 **0.015%** (0.00015).
- 매도 수수료+세금 **0.20%** (0.0020).

---

## 4. 단계별 로드맵 (Milestone)

**규칙:** 한 단계가 **완전히 돌아가고**, 유저 확인 후 다음 단계로 간다.

### 개발 집중 방향 (데이터 현실)

- **국내 주식 무료 데이터 한계**를 감안해, 당장은 **[1단계] 일봉**과 **[3단계] 주봉** 위주로 진행한다.
- **[2단계] 시간봉**은 무료로 맞추기 어려우면, **가상화폐(예: 빗썸·업비트 API)** 로 자산을 바꿀지 **유저와 먼저 상의**한 뒤 진행한다.

### [1단계] 기본 프레임 + 일봉(Daily) — 싱글 종목

**목표:** 일봉 1종목, 500만 원 **전액** 투입·전량 매매, 성과표 + 그래프까지 **실행 가능**.

**해야 할 것:**

- FinanceDataReader 로 **국내 시장** 가격 데이터.
- **종목 고르는 방법:** 시장 리스트에서 **키워드로 후보를 좁힌 뒤**, 그중 **코드 1개만** 선택해 백테스트 (`settings.yaml` + `python main.py --list`).
- **Warm-up:** 이평 왜곡 줄이기 위해 시작일 **이전** 데이터 확보.
- 터미널 **표** 출력.
- **1단계 시각화 마감:** `output/backtest_report.png` **정적 이미지** 한 장. (Plotly 등 인터랙티브 차트는 **엔진 완성 뒤** 후속.)

### [2단계] 시간봉 확장 + 이평 N 자유 입력 (보류·협의)

- 진행 전: **무료 데이터 전략**을 유저와 합의(필요 시 크립토 등).
- 합의 후: 시간봉 수집, N 변수화, “이번 봉 종가 확정 → 다음 봉 시가 체결” 유지.

### [3단계] 주봉 + 설정/CLI 강화

**목표:** 일봉 → 주봉 리샘플 후 주간 이평 시뮬, 입력은 YAML/CLI 로 **코드를 안 열어도** 되게.

**구현 요약 (현재):**

- `strategy.interval`: `daily`(일봉) 또는 `weekly`(주봉). 주봉은 일봉을 **금요일 말(`W-FRI`)** 기준으로 묶어 집계한다.
- 같은 전략·체결 규칙을 주봉에 그대로 적용한다.
- **CAGR:** 일봉일 때 연환산 분모 **252**, 주봉일 때 **52**(주 수 기준 근사).
- **CLI 덮어쓰기:**  
  `--interval daily|weekly`, `--start`, `--end`, `--keyword`, `--market`, `--code`, `--ma`

### [4단계] 과거 유니버스 추적 (생존 편향 최종 제거)

- 과거 시점의 실제 리스트·상폐 종목 반영 등. (별도 지시 후 진행.)

---

## 5. 성적표 지표

**표시:** 퍼센트(%)는 **소수 둘째 자리**까지 (예: `12.34%`).

포함 항목:

1. **누적 수익률(%)**
2. **CAGR (%):** `(최종자산 / 최초자산) ^ (1 / (전체거래일수 / 252)) - 1` 를 퍼센트로 표시.  
   - **구현:** 일봉은 분모 **252**, 주봉은 **52**(봉 개수로 나눈 “해 수”에 맞춤).
3. **MDD (최대 낙폭, %):** 지식 베이스 정의는  
   `Drawdown = (누적최대수익률 - 현재수익률) / 누적최대수익률`, `MDD = max(Drawdown)` 이다.

> **구현 메모 (1단계):** 위 MDD 분수 정의는 **누적 최고 수익률이 0에 매우 가까울 때** 값이 비정상적으로 커질 수 있다. 그래서 **1단계 코드**에서는 성적표의 MDD를 **평가액(자산) 최고점 대비 낙폭** `(피크 자산 - 현재 자산) / 피크 자산` 의 최댓값으로 표시한다. (신뢰 가능한 숫자 우선.)

---

## 6. 개발자에게 전하는 말

이 프로젝트는 **자동 매매가 아니다.** 가설을 과거에 대입해 **성적과 그래프**를 내는 **분석용**이다.

**[1단계]**·**[3단계](일봉/주봉·YAML/CLI)**·**시각화(§8)** 가 돌아가고 `output/backtest_report.png` 가 나오는 것을 기준으로, 다음 본격 작업은 **[4단계] 과거 유니버스·생존 편향 제거**다.

---

## 7. 클라이언트(유저) 추가 확정 사항 (개발자 필독)

1. **유니버스:** 전종목 분산 투자 **아님**. 키워드 등으로 **후보 리스트**를 만든 뒤, 그중 **선택한 종목 1개만** 매수·매도한다. 초기 **500만 원 전액** 투입.
2. **데이터·단계:** 무료 한계를 감안해 **1단계(일봉)·3단계(주봉)** 에 집중. **2단계(시간봉)** 는 무료 구현 방안으로 **가상화폐 API 등 전환** 여부를 **유저와 사전 상의**.
3. **표기:** 성적표의 **모든 % 지표**는 **소수 둘째 자리** (예: `12.34%`).
4. **차트:** 산출물은 `output/backtest_report.png` **정적 이미지**. 인터랙티브(Plotly 등)는 **후순위**. 다만 **§8** 처럼 정적 PNG 안에서도 **매매 타점 표기**는 한다.

---

## 8. 시각화 — 매매 타점 표기 (필수)

`output/backtest_report.png` 를 만들 때 **누적 수익률 선만** 그리지 않는다.

- **윗판:** 해당 봉 기준 **종가 추이선(검은 실선)** 위에, 실제 **체결일·체결가(시가)** 를 표시한다.
  - **매수 체결:** **빨간색 상향 삼각형(`^`)** — `matplotlib` 산점도 마커로 구현 (유저 가이드의 ▲와 동일 역할).
  - **매도 체결:** **파란색 하향 삼각형(`v`)** — 동일하게 ▼ 역할.
- **아랫판:** **누적 수익률(%)** 곡선을 유지해 성과 흐름을 같이 본다.
- **목적:** 익봉 시가 체결 원칙이 **날짜·가격**과 맞게 찍혔는지 눈으로 검증하기 위함.

---

## 9. 파이썬 가상환경 (필수)

- **규칙:** `d:\develop\BackTesterKRX` 안에서 **`venv`** 를 만들고, **항상 활성화한 뒤** 개발·실행한다.
- **금지:** 전역(글로벌) 파이썬에 이 프로젝트용 패키지를 섞어 설치하지 않는다.
- **공통 환경:** 루트의 **`requirements.txt`** 만으로 같은 버전 묶음을 복제한다.

**최초 (PowerShell 예):**

```powershell
cd D:\develop\BackTesterKRX
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**이후 매 세션:** `.\venv\Scripts\Activate.ps1` → `python main.py`
