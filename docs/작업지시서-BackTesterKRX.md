# BackTesterKRX 작업지시서 (국장 퀀트 백테스터)

이 글은 **무엇을 만들지**, **어떤 순서로 만들지**, **숫자는 어떻게 낼지**를 적어 둔 공식 기준이다.

---

## 1. 프로젝트가 하는 일

- **목적:** 실전 매매 연동 **없음**. 과거 데이터만으로 가설을 검증하는 **순수 백테스트** 프로그램.
- **핵심 가치:** 봉 주기, 이평선 **N**, 종목 선택을 바꿀 때마다 **성적표 + 정적 그래프**가 갱신되어, 아이디어를 빠르게 확인할 수 있게 한다.

---

## 2. 이 프로그램이 하지 않는 일

- 실시간 자동 매매.
- 증권사 API 주문 연동.

---

## 3. 매매 규칙 (신호 정의 + 체결)

**용어:** “이평선” = 사용자가 정한 **N기간** 이동평균(종가 기준).

### 진입 (골든크로스)

- 전일 종가 ≤ 이평선, 당일 종가 > 이평선 → 그날 **종가**에서 신호 확정.

### 청산 (데드크로스)

- 전일 종가 ≥ 이평선, 당일 종가 < 이평선 → 그날 **종가**에서 신호 확정.

### 체결

- 신호는 **그 봉 종가**에서 확정.
- 가상 체결은 **다음 봉 시가**다. (일봉 → 다음 거래일 시가, 주봉 → **다음 주 봉의 시가**.)

### 비용

- 매수 수수료 **0.015%** (0.00015).
- 매도 수수료+세금 **0.20%** (0.0020).

---

## 4. 단계별 로드맵 (Milestone)

**규칙:** 한 단계가 **완전히 돌아가고**, 유저 확인 후 다음 단계로 간다.

### 개발 집중 방향 (데이터 현실)

- **국내 주식 무료 데이터 한계**를 감안해, 당장은 **[1단계] 일봉**과 **[3단계] 주봉** 위주로 진행한다.
- **[2단계] 시간봉**은 무료로 맞추기 어려우면, **가상화폐(예: 빗썸·업비트 API)** 로 자산을 바꿀지 **유저와 먼저 상의**한 뒤 진행한다.

### [1단계] 기본 프레임 + 일봉(Daily) — 싱글 종목

**목표:** 일봉 1종목, 500만 원 **전액** 투입·전량 매매, 성과표 + 그래프까지 **실행 가능**.

**해야 할 것:**

- FinanceDataReader 로 **국내 시장** 가격 데이터.
- **종목 고르는 방법:** 시장 리스트에서 **키워드로 후보를 좁힌 뒤**, 그중 **코드 1개만** 선택해 백테스트 (`settings.yaml` + `python main.py --list`).
- **Warm-up:** 이평 왜곡 줄이기 위해 시작일 **이전** 데이터 확보.
- 터미널 **표** 출력.
- **1단계 시각화 마감:** `output/backtest_report.png` **정적 이미지** 한 장. (Plotly 등 인터랙티브 차트는 **엔진 완성 뒤** 후속.)

### [2단계] 시간봉 확장 + 이평 N 자유 입력 (보류·협의)

- 진행 전: **무료 데이터 전략**을 유저와 합의(필요 시 크립토 등).
- 합의 후: 시간봉 수집, N 변수화, “이번 봉 종가 확정 → 다음 봉 시가 체결” 유지.

### [3단계] 주봉 + 설정/CLI 강화

**목표:** 일봉 → 주봉 리샘플 후 주간 이평 시뮬, 입력은 YAML/CLI 로 **코드를 안 열어도** 되게.

**구현 요약 (현재):**

- `strategy.interval`: `daily`(일봉) 또는 `weekly`(주봉). 주봉은 일봉을 **금요일 말(`W-FRI`)** 기준으로 묶어 집계한다.
- 같은 전략·체결 규칙을 주봉에 그대로 적용한다.
- **CAGR:** 일봉일 때 연환산 분모 **252**, 주봉일 때 **52**(주 수 기준 근사).
- **CLI 덮어쓰기:**  
  `--interval daily|weekly`, `--start`, `--end`, `--keyword`, `--market`, `--code`, `--ma`

### [4단계] 과거 유니버스 추적 (생존 편향 최종 제거)

- 과거 시점의 실제 리스트·상폐 종목 반영 등. (별도 지시 후 진행.)

---

## 5. 성적표 지표

**표시:** 퍼센트(%)는 **소수 둘째 자리**까지 (예: `12.34%`).

포함 항목:

1. **누적 수익률(%)**
2. **CAGR (%):** `(최종자산 / 최초자산) ^ (1 / (전체거래일수 / 252)) - 1` 를 퍼센트로 표시.  
   - **구현:** 일봉은 분모 **252**, 주봉은 **52**(봉 개수로 나눈 “해 수”에 맞춤).
3. **MDD (최대 낙폭, %):** 지식 베이스 정의는  
   `Drawdown = (누적최대수익률 - 현재수익률) / 누적최대수익률`, `MDD = max(Drawdown)` 이다.

> **구현 메모 (1단계):** 위 MDD 분수 정의는 **누적 최고 수익률이 0에 매우 가까울 때** 값이 비정상적으로 커질 수 있다. 그래서 **1단계 코드**에서는 성적표의 MDD를 **평가액(자산) 최고점 대비 낙폭** `(피크 자산 - 현재 자산) / 피크 자산` 의 최댓값으로 표시한다. (신뢰 가능한 숫자 우선.)

### 5.1 사용자 화면 표기 (GUI·CLI, v2.4)

내부 구현·주석·수식 설명에서는 **CAGR**, **MDD** 등 영문 약어를 써도 된다. 다만 **`summary_rows` 로 GUI(`CTkTextbox`)·터미널 표에 넣는 첫 번째 열(항목명)** 은 유저 친화적으로 다음처럼 **한글 고정**으로 맞춘다.

| 내부 지표 | 표에 쓰는 이름 |
|-----------|----------------|
| CAGR      | **연평균 수익률** |
| MDD       | **최대 손실 낙폭** |

예: `CAGR: -4.03%` 가 아니라 `연평균 수익률: -4.03%`, `MDD: 55.26%` 가 아니라 `최대 손실 낙폭: 55.26%`.

---

## 6. 개발자에게 전하는 말

이 프로젝트는 **자동 매매가 아니다.** 가설을 과거에 대입해 **성적과 그래프**를 내는 **분석용**이다.

**[1단계]**·**[3단계]**·**§8 시각화**·**§10 GUI(v2.4)** 까지가 현재 구현 범위다. **[4단계] 과거 유니버스·생존 편향 제거**는 **GUI 안정화 이후** 순차 진행한다.

---

## 7. 클라이언트(유저) 추가 확정 사항 (개발자 필독)

1. **유니버스:** 전종목 분산 투자 **아님**. 키워드 등으로 **후보 리스트**를 만든 뒤, 그중 **선택한 종목 1개만** 매수·매도한다. 초기 **500만 원 전액** 투입.
2. **데이터·단계:** 무료 한계를 감안해 **1단계(일봉)·3단계(주봉)** 에 집중. **2단계(시간봉)** 는 무료 구현 방안으로 **가상화폐 API 등 전환** 여부를 **유저와 사전 상의**.
3. **표기:** 성적표의 **모든 % 지표**는 **소수 둘째 자리** (예: `12.34%`).
4. **차트:** 산출물은 `output/backtest_report.png` **정적 이미지**. 인터랙티브(Plotly 등)는 **후순위**. 다만 **§8** 처럼 정적 PNG 안에서도 **매매 타점 표기**는 한다.

---

## 8. 시각화 — 매매 타점 표기 (필수)

`output/backtest_report.png` 를 만들 때 **누적 수익률 선만** 그리지 않는다.

- **윗판:** **종가 추이선(검은 실선)** 과 같은 축 위에, **체결 시점·시가** 기준 **매매 타점**을 찍는다.
  - **매수 체결:** **빨간색 상향 삼각형(`^`)** — `matplotlib` 산점도 마커로 구현 (유저 가이드의 ▲와 동일 역할).
  - **매도 체결:** **파란색 하향 삼각형(`v`)** — 동일하게 ▼ 역할.
- **아랫판:** **누적 수익률(%)** 곡선을 유지해 성과 흐름을 같이 본다.
- **v2.1 추가:** 마커 **크기 축소**, 종가선과 **겹치지 않게** 매수는 선 **아래**, 매도는 선 **위**로 세로 **오프셋**(간격) 적용. (구현: `src/metrics.py` 의 마커 상수)

## 9. 파이썬 가상환경 (필수)

- **규칙:** `d:\develop\BackTesterKRX` 안에서 **`venv`** 를 만들고, **항상 활성화한 뒤** 개발·실행한다.
- **금지:** 전역(글로벌) 파이썬에 이 프로젝트용 패키지를 섞어 설치하지 않는다.
- **공통 환경:** 루트의 **`requirements.txt`** 만으로 같은 버전 묶음을 복제한다.

**최초 (PowerShell 예):**

```powershell
cd D:\develop\BackTesterKRX
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**이후 매 세션:** `.\venv\Scripts\Activate.ps1` → `python main.py` (GUI 는 인자 없음, CLI 는 `--list` 등). **GUI 코드 저장 시 자동 재시작이 필요하면** `python main.py --watch` (`watchdog` 패키지 포함).

## 10. GUI 화면 (v2.1 ~ v2.4)

### 10.1 현재 상황 (팩트)

- **완료:** [1단계] 일봉 엔진, [3단계] 주봉·YAML/CLI, **§8** 종가+매매 타점 PNG, **v2.1** 차트 마커, **v2.2~2.4** 화면·추세선·정적 차트·성과표 한글 라벨. **v2.3** 에서 시험한 matplotlib **내장 줌/툴바**는 축 표시 오류 등으로 **v2.4에서 제거**, 우측은 다시 **`output/backtest_report.png` 를 `CTkImage` 로 표시**한다.
- **미착수:** [4단계] 과거 시점 유니버스·생존 편향 최종 제거 — **GUI 안정화 후** 진행.

### 10.2 목적

- 검은색 터미널만이 아니라, **마우스로 조건 입력·결과 확인**하는 **데스크톱 GUI** 제공.

### 10.3 화면 구성

- **한 창**, 가로 **반반**: **왼쪽 입력**, **오른쪽 결과**.
- **왼쪽:** 시장(KOSPI/KOSDAQ), 키워드·**종목 검색** 버튼, 리스트에서 **종목 1개 선택**, 일봉/주봉, 시작·종료일, 가상 원금(기본 500만), 이평 N(기본 20), **장기 추세선**(120·200 일/봉 이평, 체크 시 차트에만 표시·전략 신호는 **변경 없음**), **백테스트 실행** 버튼.
- **오른쪽 위:** 성적표 텍스트(초기·최종·누적·연평균 수익률·최대 손실 낙폭 등, **소수 둘째 자리**, §5.1 한글 라벨).
- **오른쪽 아래:** `output/backtest_report.png` 를 **`CTkImage`** 로 표시(**v2.4**). 창·패널 크기 변경 시 이미지는 **비율 유지**로 다시 맞춘다. (전체 기간은 **엔진이 그린 PNG**에 담기며, GUI는 툴바·축 줌을 쓰지 않는다.)

### 10.4 기술
- **엔진:** `src/metrics.py` 의 `run_backtest_detailed()` 가 **파이프라인(지표·PNG 포함)** 을 조립하고, `src/data_loader.py`, `strategy.py`, `simulator.py` 와 함께 시그널·체결·비용·성과·PNG 규칙을 수행한다. (GUI 위젯 비의존.)
- **GUI:** **CustomTkinter** — 화면 코드는 **`src/gui.py`**. 차트는 PNG 파일만 표시(필요 시 `PIL`·`CTkImage`). 실행은 루트 **`main.py`** 인자 없음. 의존성: `requirements.txt` 의 `customtkinter`, `matplotlib` 등.
- **CLI:** 루트 **`main.py`** 에 `--list` 등 인자가 있으면 argparse·표 출력으로 같은 엔진을 호출한다.
- **응답성:** 백테스트는 **백그라운드 스레드**, 완료 후 UI 갱신(창 멈춤 방지).

### 10.5 실행

```powershell
cd D:\develop\BackTesterKRX
.\venv\Scripts\Activate.ps1
python main.py
```

### 10.6 [중요] 소스코드 모듈화 고도화 지침

- **금지:** 모든 코드를 `main.py` 한 파일에 몰아 넣지 않는다.
- **분리:** UI 관련 코드는 **`src/gui.py`** 에 둔다. 백테스트 핵심 계산은 **`src/data_loader.py`**, **`src/strategy.py`**, **`src/simulator.py`**, **`src/metrics.py`** 로 **파일 단위**로 나눈다. (`metrics.py` 에 성과·정적 PNG·`run_backtest_detailed` 조립 포함.)
- **UI 역할:** 사용자 입력(종목·기간·N·주기 등)을 **설정 dict** 로 엔진에 넘기고, 돌려받은 **텍스트 성과·이미지 경로**만 화면에 그린다.
- **향후 고도화:** `src/metrics.py` 에 지표·PNG·`run_backtest_detailed` 가 함께 모여 있으므로, GUI·엔진 안정화 이후 **파이프라인 조립**과 **차트 출력**을 모듈 단위로 다시 나누는 리팩터링을 검토할 수 있다.
