# v9.0.0 대형주 피보나치 스윙 (Risk-Free Swing) 설계

## 1. 패러다임 전환
- **v8.0 ORB 폐기:** 분봉·틱·09:00 돌파 전략 중단.
- **v9.0 채택:** 15:20 일봉 종가 단일 파이프라인. API·슬리피지 부담 최소.

## 2. 자금 관리
| 항목 | 값 |
|------|-----|
| 총 운용 자금 | 2,000,000원 |
| 최대 슬롯 | 4종목 |
| 슬롯당 상한 | 500,000원 |
| 1차 (0.382) | 125,000원 (25%) |
| 2차 (0.500) | 125,000원 (25%) |
| 3차 (0.618) | 250,000원 (50%) |

## 3. 유니버스
- **포함:** KOSPI200·KOSDAQ150 편입 또는 시총 ≥ 1조 원
- **제외:** 시총 < 5,000억 원 (관리·환기종목은 실전 SSOT에서 추가)

## 4. 진입 (15:20 종가)
1. MA60이 MA200을 상향 돌파(골든크로스) — 최근 63~126영업일 내
2. GC 이후 스윙 고점·저점으로 피보나치 0.382/0.500/0.618 산출
3. 종가가 해당 레벨 ±1.5% 이내 → 분할 매수 격발

## 5. 청산 (Risk-Free)
1. **50% 익절:** 종가 > 스윙 고점
2. **Risk-Free:** 잔량 손절가 = 평단(본전)
3. **전량 손절:** 3차까지 체결 후 스윙 저점(0라인) 이탈 또는 1:2 손절가

## 6. 모듈 맵
| 파일 | 역할 |
