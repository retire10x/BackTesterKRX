# 백테스트 규칙 (이 프로그램이 지키는 약속)

**전체 설계·단계·유저 확정 사항:** [작업지시서-BackTesterKRX.md](작업지시서-BackTesterKRX.md)

## 유니버스 ([1단계])

- **싱글 종목:** 후보는 `settings.yaml` 의 `search_keyword` 로 좁힌다.
- **선택:** 그중 `universe.selected_code` **한 종목**만 거래한다.
- **후보만 보기:** `python main.py --list`

## GUI (v2.4)

- 화면 코드: **`src/gui.py`**. 실행: 인자 없이 **`python main.py`** (venv). 상세는 [작업지시서 §10](작업지시서-BackTesterKRX.md).
- **차트:** 엔진이 저장한 **`output/backtest_report.png`** 를 우측에 **`CTkImage`로 표시**(전체 기간·비율은 PNG와 동일). **v2.3** matplotlib **내장 툴바/줌은 사용하지 않음**(오작동 방지).
- **v2.2 유지:** 종목 검색 **건수 팝업 없음**, **120/200** 추세선 옵션(차트만).
- **성과표 라벨:** GUI·CLI 표에서 **연평균 수익률**(CAGR), **최대 손실 낙폭**(MDD) — [작업지시서 §5.1](작업지시서-BackTesterKRX.md).

- `strategy.interval`: **일봉**(`daily`) 또는 **주봉**(`weekly`).
- **주봉:** 일봉을 **금요일 기준 주**로 묶어 Open/High/Low/Close 집계 후, 같은 신호·체결 규칙 적용.
- **CLI:** `python main.py --interval weekly` 등으로 YAML 을 덮어쓸 수 있음.

## 신호 (요약)

- **살기(골든):** 전 봉 종가 ≤ 이평, 이번 봉 종가 > 이평 → 이번 봉 종가 확정, **다음 봉 시가** 매수.
- **팔기(데드):** 전 봉 종가 ≥ 이평, 이번 봉 종가 < 이평 → 이번 봉 종가 확정, **다음 봉 시가** 매도.

## 자금

- 초기 **500만 원**을 **한 종목에 전액** 넣는 시뮬이다. (여러 종목으로 쪼개지 않음.)

## 익일 시가 체결

- 신호는 **그날 종가** 기준, 체결은 **다음 거래일 시가**.

## 성적표

- **%** 는 **소수 둘째 자리**까지.

## 그래프

- 저장 파일: **`output/backtest_report.png`** (CLI·GUI 동일 산출물).
- **GUI(v2.4):** 위 PNG 를 우측 패널에 **이미지로 표시**(축 임의 줌 없음 → 전체 구간이 PNG와 같이 보임).
- **윗판:** **종가** 곡선 + (선택) **120·200 장기 이평(주황·보라, 얇은 선)** + **매수·매도 체결** 타점.
  - 매수: 빨간 **^** (▲), **종가선보다 약간 아래**(세로 오프셋)로 그려 선과 겹침 최소화.
  - 매도: 파란 **v** (▼), **종가선보다 약간 위**.
  - 마커 **크기는 작게** 유지.
- **아랫판:** **누적 수익률(%)**.

## MDD ([1단계] 코드)

- 작업지시서의 “수익률 분수” 정의 대신, **평가액 최고점 대비 낙폭**으로 표시한다. (이유는 작업지시서 §5 참고.)
