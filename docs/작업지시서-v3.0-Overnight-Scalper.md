# 작업지시서: v3.0 오버나이트 스캘퍼 (Overnight Scalper)

## 1. 개요

일봉 OHLCV 규격 내에서 **[당일 종가 매수 → 익일 시가 매도]** 오버나이트 전략을 시뮬레이션합니다.  
장중 고저 순서를 추정하지 않으며, 익일 시가 청산으로 봉 내부 Bias를 방지합니다.

## 2. 파이프라인

| 단계 | 모듈 | 역할 |
|------|------|------|
| 1 | `src/data_loader.py` | `load_v3_0_overnight_scalper_data()` — Universe + OHLCV |
| 2 | `src/v3_signal_generator.py` | `generate_v3_overnight_signals()` — 종가 진입 필터 |
| 3 | `src/v3_execution_engine.py` | `execute_v3_overnight_backtest()` — 익일 시가 청산 |
| 4 | `src/v3_metrics.py` | `run_v3_analytics()` — PERFORMANCE REPORT |

## 3. 진입 조건 (종가)

- **A:** `당일 거래량 / 전일 거래량 >= 1.5`
- **B:** `(종가 - 시가) / 시가 * 100 >= 4.0%`
- **C:** `(고가 - 종가) / (고가 - 시가) <= 0.2` (분모 0 시 미진입)

## 4. 청산·비용 (고정)

- `BUY_COST = 0.00015`, `SELL_COST = 0.0020` (`src/v3_execution_engine.py` 상수)
- `real_buy = Close * (1 + BUY_COST)`
- `real_sell = next_Open * (1 - SELL_COST)`
- `trade_return = real_sell / real_buy - 1`

## 5. CLI

```bash
python main.py --mode cli --config config/settings.yaml
```

터미널에는 v3.0 PERFORMANCE REPORT(또는 `NO OVERNIGHT TRADES FOUND.`)만 출력합니다.

## 6. Definition of Done

- `SELL_COST = 0.0020` 스크립트 고정
- Look-ahead 없음: 진입은 당일 OHLCV, 청산은 `Open.shift(-1)` 만 사용
- `progress.md` v3.0 체크리스트·Changelog 반영
